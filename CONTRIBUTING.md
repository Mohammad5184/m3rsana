# Contributing to M3rsana

Thank you for helping improve M3rsana.

## Ground rules

- Keep modules focused and small.
- Use Bash compatible with Ubuntu 22.04 and 24.04.
- Run `./tests/syntax.sh` before submitting changes.
- Run ShellCheck and resolve actionable warnings.
- Do not introduce destructive behavior without explicit confirmation, dry-run support, backups, and documentation.
- Never commit secrets, tokens, private keys, or server credentials.

## Pull requests

Explain what changed, why it changed, and how it was tested.

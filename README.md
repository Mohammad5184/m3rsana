# M3rsana

**M3rsana** is an open-source Ubuntu server administration toolkit created to make routine maintenance safer, clearer, and more enjoyable.

> M3rsana — Your Ubuntu Server, Simplified.

## Project status

This repository is currently at **v0.1.0-dev**. It contains the project foundation, interactive dashboard, configuration loader, logger, basic health checks, installer, uninstaller, and GitHub Actions checks.

The cleanup module is intentionally non-destructive in this development release.

## Supported systems

Initial targets:

- Ubuntu Server 22.04 LTS
- Ubuntu Server 24.04 LTS

## Install from a cloned repository

```bash
sudo bash install.sh
m3rsana
```

## Available commands

```bash
m3rsana
m3rsana dashboard
m3rsana health
m3rsana cleanup --dry-run
m3rsana version
m3rsana help
```

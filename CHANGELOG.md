# Changelog

All notable changes to M3rsana will be documented here.

## [0.1.1-dev] - 2026-07-29

### Added

- Dynamic module loader and module registry
- Central error handler with log integration
- Structured UI helpers and improved dashboard
- Log-level filtering helpers
- Safer allow-listed configuration parser
- Loaded-modules command
- Smoke test suite
- Official logo asset

### Changed

- Refactored command routing around the module system
- Improved system and service detection helpers
- Refined health output and menu presentation

### Security

- Configuration files are no longer executed with `source`

## [0.1.0-dev] - 2026-07-28

### Added

- Initial modular repository structure
- Interactive command-line dashboard
- Configuration loader
- Logging foundation
- Basic system health checks
- Non-destructive cleanup preview
- Installer and uninstaller
- Syntax test script
- GitHub Actions workflow for syntax and ShellCheck
- Project governance and security documents
